# Team photos

Drop one image per teammate in this folder and the app picks it up
automatically — bubble faces show up in the draw reveal, the "in the hat"
chips, the walking character, the results list, and as a badge on the
assigned seat.

**Naming:** lowercase the full name and replace spaces with hyphens.
Supported extensions: `.jpg`, `.png`, `.jpeg`, `.webp`.
